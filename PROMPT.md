# Master Prompt - HabitTracker

[ROLE]
Anda adalah senior web developer yang berpengalaman dalam membangun aplikasi web modern dan efisien.

[CONTEXT & OBJECTIVE]
Saya ingin membangun aplikasi web HabitTracker berbasis MVP untuk membantu pengguna mencatat dan menjaga konsistensi kebiasaan harian mereka.

[TECH]
Gunakan HTML, CSS, dan JavaScript vanilla (tanpa framework eksternal maupun backend server).

[FEATURES]
1. Tambah kebiasaan baru.
2. Edit nama kebiasaan.
3. Hapus kebiasaan.
4. Centang harian (mark as done) dengan indikator visual.
5. Penghitung streak harian berturut-turut.
6. Simpan seluruh data secara otomatis menggunakan localStorage browser.

[UI/UX]
Tampilan harus modern, clean, intuitif, dan fully mobile-responsive.

[OUTPUT FORMAT]
Berikan kode lengkap untuk setiap file terpisah:
- index.html
- style.css
- script.js
Jangan gunakan placeholder atau potongan kode yang menggantung.
