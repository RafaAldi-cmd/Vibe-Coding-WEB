# HabitTracker (MVP)

Aplikasi pencatat kebiasaan harian modern dan minimalis untuk membantu menjaga konsistensi kebiasaan positif. Dibuat menggunakan pendekatan **Vibe Coding** dengan HTML, CSS, dan JavaScript vanilla.

## 🚀 Live Demo
- **URL Publik**: [https://stupendous-tapioca-b9cdcc.netlify.app](https://stupendous-tapioca-b9cdcc.netlify.app)

## 🎯 Fitur Utama
- **Tambah, Edit, & Hapus Kebiasaan**: Kelola daftar kebiasaan harian.
- **Centang Harian (*Mark as Done*)**: Tandai kebiasaan yang telah selesai hari ini.
- **Hitung *Streak* Otomatis**: Menampilkan jumlah hari berturut-turut keberhasilan kebiasaan (🔥).
- **Penyimpanan Lokal (*localStorage*)**: Data tersimpan otomatis di browser.
- **Tampilan *Responsive***: Nyaman diakses dari smartphone maupun komputer.

## 🛠️ Cara Menjalankan Secara Lokal
1. Ekstrak folder proyek.
2. Buka file `index.html` langsung di browser Anda.
